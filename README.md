# PodThing

Experimental standalone firmware to browse and play music from a stock iPod
Classic using Spotify Car Thing hardware. Development includes read-only iPod
USB storage access, an iTunesDB library browser, simulated playback, FFmpeg / USB
DAC output, an 800 x 480 touch UI and guarded safe ejection.

**The application source is not on this `main` branch.** Work is currently on
[`podthing-release-0.1.0-test`](https://github.com/richbeatty/PodThing/tree/podthing-release-0.1.0-test).

Read the [maintainer guide](https://github.com/richbeatty/PodThing/blob/podthing-release-0.1.0-test/docs/MAINTAINER.md)
before editing, building or testing. It records decisions, hardware findings,
releases, safety requirements and remaining work so nothing is lost.

[Releases](https://github.com/richbeatty/PodThing/releases)

Physical iPod, hub and Car Thing compatibility is still experimental. The iPod
music volume must be mounted read-only and never repaired or written by PodThing.
